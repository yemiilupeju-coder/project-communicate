# Voice clarity R&D (Nov 27, 2026) — research only, no production changes

Finds where the girl and boy voices lose clarity and texture, and tests fixes.
Report: "AAC voice quality, clarity and naturalness: R&D report".

Order of work (each script documents itself):

1. `corpus.ts` → `corpus.json`: 63-item phonetic corpus with the app's own phonemes.
2. `stages.py`: renders the corpus at each generation stage (source fp32/int8,
   pitch only, style move only, shipped). `stages_app.ts`: the app's own finish,
   rate conversion and playback trim. `stages_mp3.py`: the build's MP3 settings,
   plus 128k, 160k and Opus. `old_voices.ts`: the pre-Nov-26 voices.
3. `experiments.py`, `dose.py`: experiments A–J and a step-by-step formant lift.
4. `measure_stages.py` / `measure_list.py` (buzz and clarity), `phonetic.py`
   (American r, vowel shape), `asr.py` (machine word recognition), `trims.py`.
5. `vocoder/run_bigvgan.py`: experiment F, for a machine with internet.
6. `voice-clarity-listening-test.html`: the blind test.

Audio is not committed (it is regenerated by the scripts). Uses the
research/child-voice model and tools (kv.py, transforms.py, the pitch model).
Measures guide listening; they never replace it.
